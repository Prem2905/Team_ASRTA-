# SevaAgent — Citizen-Service Agent

Dynamic hackathon MVP for **Citizen-Service Agent That Completes Government Processes End to End**.

- Home: navbar, hero, about, footer, floating AI voice assistant
- Services: live Supabase search and service/scheme details
- AI: text chat + browser voice input/output, Gemini server integration with safe fallback and unavailable-service response
- Applications: dynamic creation and tracking
- Documents: real Supabase Storage upload through a server route
- Hidden admin: `/admin`, server-side role check, add/deactivate schemes/services, verify applications, issue certificates
- Stack: Next.js, Tailwind CSS, Supabase Auth/Postgres/Storage, optional Gemini API, Vercel

See `setup.md`.
